## Style Spine

```
STYLE SPINE
Pixel art, 16-bit era, 320×320 native resolution.
1879 Yorkshire railway station, late November, 11pm-to-dawn.
Deep ink-blue night sky (#0E1420 → #1A1F2C), amber gas-lamp pools (#C49640 → #B08A3F),
wet cobblestones, fog drifting at lamp-height.
Painterly source rendered down to crisp pixel art with limited 16-color palette.
Camera: medium-wide, slightly low angle, suggesting the detective's POV.
Mood: methodical, cold, observational — Obra Dinn meets Kentucky Route Zero.
NEGATIVE: text, watermarks, modern signage, color photographs, anime,
anti-aliased smooth edges, overly bright, neon.
```

## Generation Notes

- **4× render rule:** generate every pixel-art asset at 4× target resolution (locations 1280×1280 → 320×320; portraits 768×768 → 192×192 and 96×96; objects 256×256 → 64×64), then **nearest-neighbor** downscale. SDXL/Flux at native pixel resolutions produce soft edges; the downscale is what makes them crisp.
- **Painterly assets** (briefing + verdicts) render at 960×960 → bicubic downscale to 480×480; they should keep their brushwork, not pixel edges.
- **Fixed seed ranges per family** so re-rolls stay reproducible:
  - Location backdrops: seeds **1000–1099** (one seed per location, e.g. thornfield_crossing=1000, platform_two=1001, … carriage_siding=1007)
  - NPC portraits: seeds **2000–2099** (stationmaster=2000 … telegraph_operator=2011)
  - Cinematics (briefing + verdicts): seeds **3000–3099**
  - Hero objects: seeds **4000–4099**
- **Provenance:** capture the exact prompt + seed + model/checkpoint for every accepted image in `art/amber_cipher/PROVENANCE.txt` (and `art/ui/<family>/PROVENANCE.txt` for shared-path assets) so any asset can be re-rolled deterministically.
- **Palette lock:** after generation, run an indexed-color pass against the 12-color table above (extend to 16 with intermediate ramps) to enforce cross-asset consistency.
- **SDXL:** use a pixel-art LoRA (e.g. PixelArtSDXL) at 0.7–0.9 weight for sections 1, 2, 5; drop the LoRA entirely for sections 3–4 (painterly). CFG 6–7.
- **Flux:** native prompt adherence is strong enough without a LoRA; keep the NEGATIVE list in the prompt body since Flux has no negative-prompt channel.
- **Midjourney:** append `--ar 1:1 --style raw` for all assets; add `--no text, watermark, neon` per the spine's negative list; for pixel sections consider seeding with a 16-bit reference via `--sref`.
- **Naming:** lowercase_with_underscores, generate `v01/v02/v03` candidates per asset, promote the winner to the canonical filename.
